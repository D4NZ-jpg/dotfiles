## Documentation Lookup

When you need to search for:
- Library documentation and API references
- Code examples and usage patterns
- SDK documentation
- Framework-specific guides

Use the `context7` tools automatically for any programming-related documentation questions.

Do NOT use Context7 for:
- General knowledge questions
- Non-programming queries
- Conceptual explanations that don't require specific docs

The agent should proactively use Context7 when encountering questions about how to use libraries, frameworks, APIs, or coding patterns.
